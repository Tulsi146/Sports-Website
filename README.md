# Sports Website

A Sports Website developed as a group project using PHP, HTML, and CSS. The project focuses on presenting sports-related information through a simple and user-friendly website.

## Features
- Sports-related information
- User-friendly interface
- Website navigation
- PHP-based functionality

## Technologies Used
- HTML5
- CSS3
- PHP
- MySQL (if used)

## Project Type
Group Project

## My Role
Contributed to the development of the website as part of a team.

## How to Run
1. Install XAMPP.
2. Place the project folder inside the `htdocs` directory.
3. Start Apache in XAMPP.
4. Open `http://localhost/your-folder-name/` in your browser.
